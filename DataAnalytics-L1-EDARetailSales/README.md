# Retail Sales Data Analysis

## Project Overview

This project explores retail sales data using Python to understand sales performance, customer behavior, and product category trends.

## Tools Used

* Python
* Pandas
* Matplotlib
* Jupyter Notebook

## Dataset

The dataset contains 1,000 transactions and 9 columns, including transaction date, customer ID, gender, age, product category, quantity, price per unit, and total amount.

## Key Findings

* Total revenue: 456,000
* Total transactions: 1,000
* Electronics generated the highest revenue.
* Clothing had the highest quantity sold.
* Female customers accounted for slightly higher total sales than male customers.

## Conclusion

This analysis uses data exploration and visualizations to identify useful patterns in retail sales and support business decision-making.
