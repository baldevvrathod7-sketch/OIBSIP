# Retail Sales Data Analysis

## Project Overview

This project explores retail sales data using Python to understand sales performance, customer behavior, and product category trends.

## Tools Used

* Python
* Pandas
* Matplotlib
* Jupyter Notebook

## Dataset

The dataset contains 1,000 transactions and 9 columns, including transaction date, customer ID, gender, age, product category, quantity, price per unit, and total amount.

## Key Findings

* Total revenue: 456,000
* Total transactions: 1,000
* Electronics generated the highest revenue.
* Clothing had the highest quantity sold.
* Female customers accounted for slightly higher total sales than male customers.

* ## Dataset Source

The dataset used in this project is the Retail Sales Dataset available on Kaggle.

Dataset Link: https://www.kaggle.com/datasets/mohammadtalib786/retail-sales-dataset

## How to Run the Project

1. Download or clone this repository.
2. Download the retail sales dataset from Kaggle.
3. Place the CSV file in the same folder as the Jupyter Notebook.
4. Open `Retail_Sales_Analysis.ipynb` in Jupyter Notebook.
5. Run the cells sequentially to explore the data, perform analysis, and generate visualizations.

## Project Structure

* `Retail_Sales_Analysis.ipynb` — Python code, data analysis, and visualizations.
