# Customer Segmentation Analysis

Oasis Infobyte Data Analytics Internship — Task 2

## Project Overview

This project uses customer transaction data to identify different customer segments based on their purchasing behaviour.

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Jupyter Notebook

## Methodology

1. Data cleaning and preprocessing
2. Recency, Frequency, and Monetary (RFM) analysis
3. Feature scaling
4. K-Means clustering
5. Customer segment analysis and visualization

## Results

Customers were grouped into three clusters: Inactive Customers, Regular Customers, and High-Value Customers.

## Files

* `Customer_Segmentation.ipynb` — Jupyter Notebook containing the analysis.
* `Online Retail.xlsx` — Dataset used for the project.
